# Computer Virus Fighting Game

The Computer Virus Fighting Game, a Simple Top-down Vibecoded Shooter Game about Fighting Computer Viruses.

## Controls
### Keyboard
- WASD --> Movement
- Shift --> Dash
- Mouse --> Aim
- Left Click --> Shoot Weapon
- Scroll Wheel / 1-4 --> Switch Weapon
- Tab --> Map

### Controller
- Left Joystick --> Movement
- Right Trigger --> Dash
- Right Joystick --> Aim
- Right Button --> Shoot Weapon
- Left and Right D-pad --> Switch Weapon
- Start --> Map
